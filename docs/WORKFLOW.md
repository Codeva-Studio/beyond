# BEYOND workflow

## Repository language

Write repository-facing documentation, Issues, Pull Requests, commits, and Release notes in English.

## Work lifecycle

1. Create an Issue when work needs discussion or tracking.
2. Create a focused branch from `develop`.
3. Implement the change in small, understandable commits.
4. Open a Pull Request targeting `develop`.
5. Complete the Pull Request checklist and review the diff.
6. Merge after the required review and checks are complete.
7. Publish a Release from a deliberate version tag when a release is ready.
