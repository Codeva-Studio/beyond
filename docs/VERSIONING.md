# Versioning policy

When BEYOND begins publishing versioned releases, use Semantic Versioning where it fits:
`MAJOR.MINOR.PATCH`.

- **MAJOR**: an incompatible change to a published interface or behavior.
- **MINOR**: backward-compatible functionality.
- **PATCH**: backward-compatible fixes.

Before the project has a stable public compatibility contract, pre-release versions may be
appropriate, such as `0.1.0`, `0.2.0`, or `1.0.0-beta.1`.

Choose and document the policy before publishing releases. Do not create tags merely to match
an example.
