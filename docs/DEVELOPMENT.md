# Development guide

This guide describes the development workflow. It intentionally does not invent
framework commands or setup steps.

## Local setup

Follow the confirmed installation and run instructions in the root README.
Keep project-specific commands there or in a dedicated setup section once verified.

## Quality checks

Run the checks that are actually configured for BEYOND before opening a Pull Request.
Do not copy commands from another project or claim a check passed unless it ran.

## Change discipline

- Keep changes focused and reviewable.
- Update documentation when behavior or setup changes.
- Do not commit secrets, local environment files, or unrelated generated output.
