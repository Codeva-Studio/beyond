# Repository labels

The label catalogue is documented in [`.github/labels.yml`](../.github/labels.yml).

GitHub does not import that file automatically. Create or update labels in the repository's
**Issues > Labels** settings, or use an explicitly configured and reviewed automation.

Keep label meanings consistent. Before adding a label, check whether an existing label already
covers the same purpose. Review color contrast and avoid relying on color alone to communicate meaning.
