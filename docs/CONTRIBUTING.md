# Contributing to BEYOND

## Before starting

- Read the root README and relevant project documentation.
- Search existing Issues and Pull Requests to avoid duplicate work.
- Discuss substantial changes in an Issue before implementation.

## Contribution process

1. Create or select an Issue when the work needs tracking.
2. Create a focused branch from `develop`.
3. Make small, understandable commits.
4. Open a Pull Request targeting `develop`.
5. Complete the Pull Request template and explain how the change was verified.
6. Respond to review feedback and keep the branch focused.

## Communication

Use English for repository-facing Issues, Pull Requests, commits, and documentation.
Be respectful, specific, and constructive.
